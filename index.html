📖 Statistical protocol
▼

PRISM-V uncertainty was estimated with 10,000 paired bootstrap replicates. LJSpeech was resampled at the utterance level, while Free_ST, LibriTTS, and VCTK used speaker-cluster resampling. Identical sampled units were applied across systems within each replicate. All C(15,2)=105 system pairs formed one multiple-comparison family, with Holm-Bonferroni correction at α=0.05. Pairwise results report PRISM-V score differences with paired 95% bootstrap confidence intervals.

Speaker-Cluster Resampling: Applied to Free_ST (10 speakers), LibriTTS (682 speakers), and VCTK (109 speakers). Preserves inter-speaker acoustic correlation structure.
Holm-Bonferroni Family-Wise Control: Step-down adjustment over sorted p-values $p_{(1)} \le \dots \le p_{(m)}$ testing $H_{(k)}$ at $\alpha / (m - k + 1)$, with $m = 105$. Controls FWER at 0.05 without conservatism of standard Bonferroni.

➕ Submit a Vocoder Model to the Leaderboard

We warmly welcome researchers and speech synthesis teams to submit neural vocoders to PRISM-V. Follow the open-source GitHub workflow below to fork the repository into your personal account, implement the adapter, and open an upstream Pull Request.

🍴 1. Fork to Your Account 🔀 2. Submit Pull Request 📦 View Repository

Submission Criteria

1. Public Model Checkpoints

Weights hosted publicly on Hugging Face Hub, GitHub Releases, or Zenodo accessible without proprietary credentials.

2. Open Inference Code

Open-source license (MIT, Apache-2.0, BSD, CC-BY) with reproducible PyTorch dependencies via standard pip install.

3. Standardized Mel Adapter

Conforming to the PRISM-V BaseVocoderAdapter interface (80-channel log-mel spectrogram input).

Community Contribution Workflow

1 Fork the Repository to Your GitHub Account
🍴 Fork on GitHub →

Click the button above or visit github.com/iamshreeji-copy2/open_vocoder_leaderboard/fork. GitHub will open the fork creation prompt under your personal profile (github.com/<your-username>/open_vocoder_leaderboard).

2 Clone Your Fork & Create a Branch

Pull your personal fork to your local workstation and create a new feature branch for your vocoder: 

# 1. Clone your personal fork (replace <YOUR-USERNAME> with your GitHub username)
git clone https://github.com/<YOUR-USERNAME>/open_vocoder_leaderboard.git
cd open_vocoder_leaderboard

# 2. Create a dedicated branch for your model
git checkout -b add-my-vocoder-model
3 Implement the BaseVocoderAdapter Interface

Create your adapter file at src/vocoder_benchmark/models/adapters/my_vocoder.py implementing the three required methods: 

from benchmark.adapters.base import BaseVocoderAdapter
import torch

class MyVocoderAdapter(BaseVocoderAdapter):
    """PRISM-V Standard Model Adapter Interface"""

    def load(self, device: str = "cuda", precision: str = "fp32"):
        """Load pretrained weights and set model to evaluation mode."""
        self.model = load_my_checkpoint(self.checkpoint_path).to(device).eval()

    def preprocess(self, waveform: torch.Tensor, sr: int) -> torch.Tensor:
        """Extract 80-band log-mel spectrogram (1024 FFT, 256 hop, 80 mels)."""
        return extract_mel_spectrogram(waveform, sr)

    @torch.no_grad()
    def infer(self, condition: torch.Tensor, seed: int = 42) -> torch.Tensor:
        """Synthesize audio waveform from conditioning mel tensor."""
        return self.model(condition)
Test your adapter locally with the self-contained verification suite:
pytest tests/test_adapters.py -k my_vocoder
4 Push to Your Fork & Open Upstream Pull Request
🔀 Open Pull Request (Compare) →

Push the branch to your personal fork on GitHub: 

git add src/vocoder_benchmark/models/adapters/ configs/models/
git commit -m "feat(adapter): add MyVocoder adapter and benchmark config"
git push -u origin add-my-vocoder-model

Then click Open Pull Request (Compare Forks). GitHub will automatically compare your fork's branch against iamshreeji-copy2/open_vocoder_leaderboard:main. Review your changes and click Create pull request.

🤖 Automated Benchmark Verification & Leaderboard Publishing

Once submitted, CI verifies model loading, determinism, and sample reconstruction. Our GPU cluster then evaluates all 5 PRISM-V dimensions across the 4 speech corpora, automatically publishing your model's scores to the public leaderboard.
