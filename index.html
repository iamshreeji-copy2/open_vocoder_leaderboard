Overview & Benchmark Motivation

Traditional neural vocoder evaluations predominantly report PESQ and MCD exclusively on clean, single-speaker studio recordings (e.g., LJSpeech). In production speech synthesis and voice conversion, however, practitioners deploy models on diverse voices, accented speech, and real-world noisy audio across hardware constrained to sub-realtime latencies.

PRISM-V establishes a comprehensive, zero-shot, training-free benchmark evaluating 15 pretrained vocoder architectures across four English acoustic corpora and five core dimensions: Perceptual quality, Reconstruction fidelity, Intelligibility preservation, Speaker identity, and Model edge efficiency.

Studio PESQ Mismatch

Models scoring >4.4 PESQ on clean LJSpeech (e.g. BigVGAN-v2, PeriodWave) show variable degradation on mobile microphone noise (Free_ST) and accented speech (VCTK). Cross-corpus evaluation is required for true generalization.

⚡

The Flow-Matching Frontier

Modern flow matching models (Flow2GAN, WaveFM) and Brownian Bridge SDEs (BridgeVoC) compress diffusion generation into 1 to 4 steps, matching 30-step diffusion fidelity at 12–35× real-time throughput.

📱

Edge Deployment Realities

Fourier / iSTFT ConvNeXt models (Vocos) and pseudo-inverse GANs (FreeV) achieve >300× throughput with under 400 MB peak VRAM, unlocking viable on-device streaming neural synthesis on edge hardware.

Design Principles

PRISM-V is a strictly training-free, zero-shot evaluation of publicly released pretrained checkpoints.

Models are evaluated exactly as practitioners deploy them: no fine-tuning, no cherry-picked test sets, and fixed deterministic seeds.

Inference Protocol

• Batch size: 1 (realistic streaming inference)

• Precision: FP32 with generator-only timing (excludes frontend mel extraction)

• Hardware Profiling: Warmup iterations + measured loops with CUDA synchronization fences

Evaluation Corpora

Corpus Acoustic Condition Characteristics

Free_ST Mobile microphone noisy Real-world acoustic environments, mobile devices, background reverberation.

➕ Submit / Request a Pretrained Vocoder

We actively welcome vocoder authors and speech researchers to submit new pretrained neural vocoders to PRISM-V.

1. Public Checkpoint

GitHub release or project page accessible without authentication.

2. Open Inference Code

Open-source license (MIT, Apache-2.0, BSD, CC-BY) with clean pip/PyTorch installation.

3. Deterministic Mel Adapter

Compatible with the standard PRISM-V BaseVocoderAdapter interface.

PRISM-V Adapter Interface Example:

from benchmark.adapters.base import BaseVocoderAdapter
import torch

class MyVocoderAdapter(BaseVocoderAdapter):
    def load(self, device, precision):
        self.model = load_my_model(self.checkpoint_path).to(device).eval()

    def preprocess(self, waveform: torch.Tensor, sr: int) -> torch.Tensor:
        return my_mel_extractor(waveform, sr)

    @torch.no_grad()
    def infer(self, condition: torch.Tensor, seed: int) -> torch.Tensor:
        return self.model(condition)
